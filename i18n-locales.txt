接入一个新语言的步骤
--------------------------------------------------------------------
1. 复制 app/web/i18n/locales/en-us.ts 为 app/web/i18n/locales/<code>.ts，逐条翻译
   （必须保留 {count} / {page} / {pages} / {min} / {max} 这些占位符原样）
2. 在 app/web/i18n.config.ts 里 import 该语言包并登记到 messages
3. 在 app/web/nuxt.config.ts 的 i18n.locales 里登记 { code, language, name, short }
   （阿拉伯语等从右到左的语言再加 dir: 'rtl'）
4. 校验：每个语言包的键必须与 zh-cn 完全一致（见 README「多语言（i18n）」一节的校验命令）
5. 区域 / 运营商的译名在同一语言包的 regions / carriers 里，键为数据中的 region / carrier 代号
